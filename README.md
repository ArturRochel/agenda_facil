# AgendaFácil

Agenda de atendimentos para uma clínica pequena. Permite **marcar**, **remarcar** e **listar** atendimentos, validando expediente, duração, conflito de horário e formato de data. Os dados vivem apenas em memória.

Projeto da Unidade 1 da disciplina DIM0501 — Boas Práticas de Programação (DIMAp/UFRN, 2026.1), versão refatorada do código-base `agenda_base.py`.
